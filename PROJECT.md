# Concrete Ideas Website

**Version:** 3.0

---

# Project Vision

Concrete Ideas is a premium architectural concrete décor brand.

The website is not an e-commerce platform.

It is a curated digital portfolio that showcases timeless architectural products and inspires architects, landscape designers, interior designers, and premium residential customers.

The website should communicate:

* Timeless Design
* Material Honesty
* Architectural Simplicity
* Craftsmanship
* Premium Quality
* Quiet Luxury

Every design decision should reinforce these principles.

---

# Mission

Create India's finest digital portfolio for premium concrete décor.

The experience should feel closer to an architectural design brand than a product catalogue.

Visitors should leave believing Concrete Ideas designs products—not simply manufactures them.

---

# Business Goals

The website should:

* Generate qualified architect enquiries.
* Increase catalogue downloads.
* Increase quote requests.
* Build brand credibility.
* Showcase craftsmanship.
* Position Concrete Ideas as a premium architectural brand.

# Content Model

The website is built around four primary entities.

## Collection

Represents a family of products.

Examples

* Landscape
* Indoor
* Bespoke

---

## Product

Contains

* Name
* Description
* Hero Image
* Gallery
* Sizes
* Material
* Finish
* Specifications
* Related Products

---

## Project

A real-world installation.

Contains

* Client
* Location
* Images
* Products Used
* Description

---

## Resource

Contains

* Product Catalogue
* Specification Sheet
* Installation Guide

---

# Product Requirements

Every product page must contain:

* Hero Image
* Product Name
* Short Description
* Technical Specifications
* Material
* Finish
* Available Sizes
* Lifestyle Gallery
* Related Products
* Request Quote CTA
* Download Catalogue CTA

Never display pricing.

---

# Collection Requirements

Every collection page must contain:

* Hero Banner
* Introduction
* Product Grid
* Related Collections
* Call To Action

---

# UX Principles

The product is always the hero.

Whitespace is part of the design.

Reduce visual noise.

Avoid unnecessary interaction.

Navigation should be obvious.

Every page should have one clear primary action.

---

# Coding Standards

Use

* HTML5
* CSS3
* Vanilla JavaScript

Reuse components.
